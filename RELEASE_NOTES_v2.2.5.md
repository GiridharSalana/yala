What's new in v2.2.5:
• Bandwidth Monitoring: Real-time client traffic rate tracking and live ingress/egress speeds.
• Smart Queue Management (SQM QoS): Complete bufferbloat management supporting Cake and FQ_Codel queue disciplines with link-layer adaptation.
• Storage & Disk Monitoring: Live tracking for root/overlay flash and external mounted USB storage with low-space alerts.
• DHCP & DNS Management: Responsive overhaul across dynamic font scales and screen sizes, plus improved static DHCP lease validation and deletion.
• System Backup & Upgrade: Interactive inspector for preserved configuration backup files (/etc/sysupgrade.conf).
• Router Hostname & RPC Management: Live router hostname editor and granular RPC permissions management dialog.
• Multi-Router & Session Hardening: Complete credential isolation during auto-login across multi-router profiles and fail-safe router switch recovery.
• F-Droid & FOSS Compliance: Locally bundled Geist and Geist Mono font families with zero runtime network fetching, and update checker suppression for F-Droid builds.

### Package Downloads
- app-arm64-v8a-release: Modern 64-bit ARM devices (most newer phones and tablets).
- app-armeabi-v7a-release.apk: Older 32-bit ARM devices.
- app-x86_64-release.apk: 64-bit x86 Android Intel/AMD tablets.
- app-universal-release.apk: Compatible with all supported Android architectures.

### Note
If you don't know which one to install, then install the universal one.
