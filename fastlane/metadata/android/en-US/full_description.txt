Manage OpenWrt routers directly from Android with a modern, high-performance native interface built for administration, wireless monitoring, and network control.

Yet Another LuCI App (YALA) is a privacy-first mobile client connecting directly to your router via standard LuCI HTTP/HTTPS and ubus JSON-RPC APIs. Designed for speed, it provides a touch-friendly alternative to mobile browsers without depending on cloud servers, external accounts, or remote telemetry.

COMPATIBLE FIRMWARES & ROUTERS
Works with OpenWrt (19.07–24.10+), ImmortalWrt, Turris OS, GL.iNet, Gargoyle, and FriendlyWrt across TP-Link, Netgear, Linksys, Asus, and x86/ARM devices with LuCI or ubus RPC.

KEY FEATURES

MULTI-ROUTER MANAGEMENT & SECURE VAULT
• Manage multiple OpenWrt routers with quick profile switching
• Encrypted local vault backed by Android Keystore
• Supports LuCI RPC, ubus JSON-RPC, and sysauth logins

CONNECTED CLIENTS & DUMB AP SUPPORT
• Live view of active wired, wireless, and DHCP lease clients
• Dumb AP support: inspect clients connected to secondary bridged APs
• Per-client real-time transfer speed badges (RX / TX)
• Filter by hostname, IP, MAC address, or Wi-Fi band
• 1-tap MAC access control and static DHCP lease management

HARDWARE TEMPERATURE & REAL-TIME VITALS
• Live SoC hardware temperature across thermal zones (°C / °F)
• CPU load, RAM usage, load averages, and uptime
• Live network throughput graphs with continuous streaming
• One-tap SSH terminal launcher and quick reboot actions

NETWORK DIAGNOSTICS SUITE
• Integrated Ping utility with latency and jitter tracking
• Visual Traceroute showing route hops and transit delays
• Real-time DNS lookup resolver (A, AAAA, CNAME)
• Gateway and WAN reachability verification

OPKG & APK PACKAGE MANAGER
• Dual package manager for opkg and modern apk (OpenWrt 24.10+)
• Tabbed browsing: Installed, Upgradable (with update badges), Available
• 1-tap batch upgrades (Upgrade All) with real-time logs
• Custom package install by name or external package URL
• Manage package feeds, repositories, and distribution URLs
• Manage system services (start/stop/restart) and crontab tasks

PARENTAL CONTROLS & SCHEDULES
• Group devices into customizable parental profiles
• Access schedules with automatic firewall enforcement
• 1-tap internet pause, resume, and temporary bypass modes

ISOLATED GUEST WI-FI
• 1-tap provisioning of dedicated guest Wi-Fi networks
• Firewall rules isolating guests from your private LAN
• L2 client isolation (ap_isolate) preventing client snooping
• Wi-Fi QR code sharing for instant guest onboarding

WIRELESS & FAST ROAMING
• Tri-band 2.4, 5, and 6 GHz radios, channels, and transmit power
• 802.11r/k/v fast roaming for seamless mesh transitions
• Monitor connected stations, signal strength (dBm), and noise floor

FIREWALL, ROUTING & VPN
• Supports both iptables (fw3) and modern nftables (fw4)
• Manage firewall zones, port forwards, and custom traffic rules
• Inspect kernel IPv4 routing tables and ARP neighbor lists
• Monitor WireGuard, OpenVPN, Tailscale, Cloudflare Tunnels, and NextDNS

LOCALIZATION & MULTI-LANGUAGE (BETA)
• Available in English, German, Spanish, French, Indonesian, Portuguese, Russian, and Simplified Chinese
• Adaptive responsive UI supporting system accessibility text scaling

SECURITY & SAFETY GUARDRAILS
• Active self-device guard prevents accidental management lockout
• Debounced, asynchronous state management for toggles & DDNS services
• Atomic UCI commits with automatic rollback on network error
• 100% Cloud-Free: Direct local connection with zero telemetry
